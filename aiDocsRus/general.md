# General

## О чём это приложение
Веб-приложение для изучения иностранных языков: английского, испанского, французского, немецкого, итальянского, турецкого и русского (список — `face/shared/utils/languages.ts`). Интерфейс переведён на те же 7 языков. Сервис бесплатный, работает как адаптивный сайт, мобильного приложения нет.

Внутри сервер использует LLM (OpenAI, DeepSeek, Gemini), генерацию изображений и озвучку.

### Главный раздел — диалоги с ИИ
Ролевая сценка на изучаемом языке по сюжету (сценарию). Сценарий задаёт только начальную сцену, дальше сюжет зависит от реплик и действий пользователя.

- На странице `/{locale}/dialogues` пользователь выбирает сценарий из групп по темам и в окне запуска задаёт язык практики, уровень сложности (A1–B2 или любой) и стиль иллюстраций.
- ИИ играет всех персонажей (NPC) и ведёт сцену. Ответ приходит потоком, у каждой реплики есть перевод на язык интерфейса.
- Пользователь пишет или диктует реплику и/или действие. Перед отправкой текст проверяется на грамматику, отправить можно только текст без критических ошибок.
- У персонажей есть портреты с эмоциями, у встреч — иллюстрации сцен, у реплик и описаний — озвучка. Клик по слову показывает его перевод в словаре.
- Диалоги сохраняются в «Моих диалогах», их можно продолжить позже.

Подробности — `aiDocsRus/topics/aiDialogue/overview.md`.

### Книги и видео
Более ранний раздел. Пользователю доступны книги и фильмы на изучаемых языках, можно загрузить свои. Сервер делит тексты и субтитры на предложения. При чтении или просмотре видео (подсвечивается текущий субтитр) пользователь нажимает на незнакомое слово и получает перевод предложения и разбор слова или фразы.

## Root folder structure
- `face` — фронтенд: Next.js, next-intl, SCSS, TanStack Query (клиент API генерируется Orval из OpenAPI), Zustand.
- `server` — бэкенд: NestJS + CQRS, REST, Prisma (PostgreSQL), Redis, BullMQ worker (изображения, озвучка, субтитры), файлы в Cloudflare R2.
- `docker` — compose-файлы и скрипты запуска.
- `nginx` — reverse proxy.
- `infrastructure` — генератор Docker-compose файлов.

## Запуск приложения
Все части приложения находятся в отдельных контейнерах. Запуск локальной разработки из папки `docker` (`run.local.dev.sh`):
```docker compose -f docker-compose.local.dev.ru.yml --project-directory .. --env-file .env.localdev up --build```
