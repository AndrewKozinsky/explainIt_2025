# Мои диалоги

Секция «Мои диалоги» страницы `/dialogues` показывает пять последних диалогов текущего пользователя.
Остальные можно загрузить кнопкой «Предыдущие диалоги». Модель диалога, создание, сообщения и удаление
описаны в [aiDialogue.md](aiDialogue.md).

## Серверный контракт

`GET /api/ai-dialogue?page=1&pageSize=10` возвращает только диалоги текущего пользователя.
По умолчанию `page=1`, `pageSize=10`. Параметры принимают целые числа, `page≥1`, `1≤pageSize≤100`.
Список отсортирован по `created_at DESC, id DESC`. Пагинация возвращает
`page`, `pageSize`, `total`, `totalPages` и `items`.

Общие поля карточки:

- `id` — идентификатор диалога.
- `scenarioTitle` — название сценария на языке интерфейса из `Accept-Language`.
- `mode` — `practice` или `exam`.
- `sourceLanguageCode` — язык диалога.
- `cefrLevel` — выбранная сложность практики (`null` означает «Без ограничения») или начальная сложность экзамена.
  Во время экзамена персонаж адаптирует речь по ходу разговора. Подтверждённый уровень вычисляется после запроса
  результата и хранится отдельно.
- `sceneImageUrl` — подписанный URL иллюстрации последнего `sceneUpdate` или `null`, если она пока не готова.
  При чтении списка генерация не запускается.

В практике `lastMessage` содержит `name`, `role`, `text`, `textType` и подписанный `avatarUrl` спрайта автора.
Используется последнее сохранённое `npcActions`, даже если вслед за ним пользователь отправил ответ
или сменилась сцена. Из него выбирается последняя непустая реплика, при её отсутствии — последнее непустое действие.
Для старого сообщения без связи с реестром NPC имя и роль берутся из сообщения, а `avatarUrl` равен `null`.
Если персонажи ещё не писали, `lastMessage` равен `null`. Поле `exam` в практике равно `null`.

В экзамене `lastMessage` равен `null`, а `exam` содержит `status`, `level` и `medalUrl`:

| Статус | Когда устанавливается | Уровень и медаль |
| --- | --- | --- |
| `inProgress` | Результат проверки ещё не сохранён | Оба поля равны `null` |
| `passed` | Подтверждён A1, A2, B1, B2 или C1 | Подтверждённый уровень и публичный URL медали исходного сценария, если она настроена |
| `failed` | Проверка вернула A0 | Оба поля равны `null` |

Подсчёт, страница и выбранные сообщения читаются в транзакции `RepeatableRead`.
Для каждого диалога выбираются ID последней смены сцены и последнего сообщения нужного типа
(`npcActions` в практике, `examResult` в экзамене). Изображение сцены и спрайт автора выбираются по их связям
с этими записями. Приватные URL подписываются после транзакции. Ответ использует `Cache-Control: private, no-store`.
Индексы для списка и сообщений — `AiDialogue (user_id, created_at, id)` и `AiDialogueMessage (dialogue_id, type, id)`.

## Клиентский список

`UserAiDialoguesList` загружает страницы по 10 записей. Изначально видны пять карточек, далее кнопка добавляет
до 10 за нажатие. Ошибка догрузки сохраняет видимые карточки. Ключ кэша включает ID пользователя.
После создания или удаления активные загруженные страницы перечитываются, чтобы смещение пагинации
не приводило к пропуску записей. После проверки экзамена список помечается для обновления.
Изменение сложности обновляет `cefrLevel` записи в кэше.

Каждая карточка — ссылка на диалог с отдельной кнопкой удаления. В общей части показаны иллюстрация, режим,
название, язык и сложность. В практике дополнительный блок показывает портрет автора, имя, роль и текст.
Портрет берётся из верхней левой ячейки спрайта, при отсутствии изображения используется первая буква имени.
В экзамене дополнительный блок показывает статус и щит либо полученную медаль.

Компоновка зависит от ширины контейнера списка. От `100rem` дополнительный блок стоит справа,
от `60rem` до `100rem` — под общей частью. Ниже `60rem` дополнительный блок скрыт в обоих режимах,
иллюстрация находится над названием.

## Проверки

- `cd server && npm test -- aiDialogueList.queryRepository getAiDialogueLastMessage` — выборка и маппинг списка.
- `cd face && npm run test:ai-dialogue` — клиентские тесты диалогов.
- `cd face && npx playwright test --config playwright.ai-dialogues.config.ts aiDialogueList.spec.ts` —
  оба режима, адаптивность, пагинация и удаление на стенде с подменённым API.
