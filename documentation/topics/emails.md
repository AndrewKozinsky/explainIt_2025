# Письма

Сервер отправляет пользователю письма авторизации: подтверждение почты после регистрации и восстановление пароля.
Письма переведены на 7 языков интерфейса и уходят на языке страницы, с которой пришёл запрос.

## Устройство

Код лежит в `server/src/infrastructure/`:

- `emailAdapter/email-adapter.service.ts` — `EmailAdapterService.send(message)` отправляет готовое письмо
  (`to`, `subject`, `text`, `html`) через Resend и ничего не знает о его содержимом. Ошибка отправки только
  логируется. В режиме `localtest` `EmailAdapterModule` подставляет `EmailAdapterServiceMock`, который ничего не
  отправляет.
- `emails/` — шаблоны писем:
  - `emailLayout.ts` — `renderActionEmail` собирает HTML- и текстовый вариант письма с одной кнопкой-действием и
    экранирует все подставляемые значения. Внизу письма — подвал с названием сайта и ссылкой на главную страницу на
    языке письма (`Immersia — immersia.site`). Название сайта в тексте письма ссылкой не делается, чтобы единственным
    заметным действием оставалась кнопка;
  - `emailConfirmationEmail.ts`, `passwordRecoveryEmail.ts` — тексты на 7 языках (`Record<Language, …>`, поэтому
    TypeScript не даёт пропустить язык) и функции сборки письма. В текстах `{siteName}` заменяется на название сайта;
  - `authEmail.service.ts` — `AuthEmailService` собирает ссылку на страницу сайта, письмо на нужном языке и передаёт
    его адаптеру. Команды авторизации вызывают его, а не адаптер.

## Язык письма

Контроллер получает язык декоратором `@RequestLocale()` из заголовка `Accept-Language` (клиент кладёт туда локаль
страницы) и передаёт его в команду. Ссылки в письмах содержат префикс языка (`/{locale}/auth/...`), потому что клиент
открывает страницы только по адресам с префиксом.

Обращение в текстах такое же, как в интерфейсе: «вы», `Sie`, `vous`, `siz`; в испанском и итальянском — `tú`/`tu`.

## Отправитель

Адрес и имя отправителя задаёт `emailAdapter` в `mainConfig.service.ts`: `noreply@` + основной домен региона
(`site.domain`), имя — название сайта. Resend отправляет только с подтверждённого домена; сейчас подтверждён
`immersia.site`, поэтому письма уходят только в регионе `intl`. Ключ API — переменная окружения `RESEND_API_KEY`.

## Как добавить письмо

1. Создать в `emails/` файл с текстами на 7 языках и функцией сборки через `renderActionEmail`.
2. Добавить метод в `AuthEmailService` (или отдельный сервис для писем другой темы), который собирает ссылку и вызывает
   `EmailAdapterService.send`.
3. Передать язык из контроллера через `@RequestLocale()`.
4. Дополнить тесты в `emails/emails.spec.ts`.
