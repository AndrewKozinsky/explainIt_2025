# Видео и фильмы: обзор

Что такое раздел видео и что в нём может пользователь. Документ описывает возможности для пользователя, а не реализацию.

## Идея

Пользователь смотрит видео на изучаемом языке с субтитрами. Нажав на незнакомое слово в субтитрах, он сразу получает
перевод предложения, разбор фразы с этим словом и словарную статью.

Видео и фильмы — почти одно и то же:

- **видео** — ролики с YouTube;
- **фильмы** — видеофайлы, которые загрузил сам пользователь.

## Список видео

Страница `/{locale}/videos` с тремя вкладками:

- **Подборка** — YouTube-видео, которые ранее смотрели другие пользователи. Фильтры по языку, длительности и уровню
  CEFR, сортировка.
- **Поиск** — поиск YouTube-видео по названию. Если ввести точную ссылку на видео YouTube, приложение сразу открывает
  страницу просмотра этого видео.
- **Мои видео** — собственные видеофайлы пользователя: просмотр и добавление.

Подборка и Поиск доступны без регистрации, Мои видео — только зарегистрированным.

## Редактирование своего видео

`/{locale}/videos/{id}?details` — можно поменять язык и название, загрузить обложку и файл видео, в блоке
«Субтитры или текст» выбрать субтитры или текст, удалить видео. Для загруженного видео можно запустить автоматическую
генерацию субтитров.

## Страница видео

Одинакова для YouTube-видео и своего видео. Слева — видео и субтитры (или текст), текущий субтитр подсвечивается.
Справа — панель со Словарём. Пользователь нажимает на слово в субтитре или тексте — что происходит дальше, описано
в [wordClick.md](wordClick.md).
