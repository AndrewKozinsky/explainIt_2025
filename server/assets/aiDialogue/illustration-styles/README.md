# Эталоны стилей иллюстраций: этап 1

Созданы 26 октября 2026 встроенным image_gen (не CLI).
Файлы для загрузки: WebP 1254×1254, квадрат 1:1, непрозрачный фон.
PNG-оригиналы сохранены в originals/. WebP получены через sharp с quality=90,
effort=6, без изменения размеров. Общий размер уменьшен с 8 191 040 до 1 028 780 байт
(примерно на 87%).
Изображения показывают одну сцену с теми же двумя взрослыми персонажами:
разговор путешественницы с администратором отеля.
Фотореализм создан первым; рисунок и акварель получены сменой художественной техники
с сохранением композиции и персонажей.

## Что загрузить в R2

Бакет: существующий CLOUDFLARE_S3_BUCKET_NAME. Оставить его приватным.
Папка (префикс объекта):

```text
ai-dialogue-images/shared/styles/<mode>/
```

| Стиль | Локальный файл | Полный ключ R2 для localdev |
|---|---|---|
| Реализм (фотореализм) | realism.webp | ai-dialogue-images/shared/styles/localdev/realism.webp |
| Рисунок | drawing.webp | ai-dialogue-images/shared/styles/localdev/drawing.webp |
| Акварель | watercolor.webp | ai-dialogue-images/shared/styles/localdev/watercolor.webp |

Content-Type каждого файла: image/webp.
Загрузить только три WebP из этой папки. originals/, README.md, assets.json
и generation-prompts.md загружать не нужно.

MODE берётся из MainConfigService, а не из названия окружения, введённого вручную.
Текущие значения конфигурации: localtest, localdev, localcheckserver, serverdevelop, servermaster.
Рабочий режим называется servermaster; productionserver сейчас в конфигурации нет.

Примеры папок:

- локальная разработка: ai-dialogue-images/shared/styles/localdev/;
- сервер разработки: ai-dialogue-images/shared/styles/serverdevelop/;
- рабочий сервер: ai-dialogue-images/shared/styles/servermaster/.

Для рабочего сервера полный ключ реализма:
ai-dialogue-images/shared/styles/servermaster/realism.webp.
Один набор из трёх WebP можно загрузить в несколько папок MODE с теми же именами.
Версионирования изображений и региональной папки нет: ru и intl могут использовать
одни эталоны своего MODE. Префикс находится вне generated/ и не относится
к изображениям конкретного диалога.

После этапа 1 пользователь загрузил файлы в R2. 26 октября 2026 проверены все три
объекта localdev: доступны, 1254×1254, image/webp.
На этапе 2 серверный каталог уже выдаёт подписанные превью и сохраняет выбор в диалоге;

## Почему квадрат подходит

В текущем dialogueImageReference/inspectDialogueImage эталон проверяется по формату,
размеру и полному декодированию; совпадение пропорций с результатом не требуется.
Адаптер передаёт файлы референсов отдельно от размера генерируемого результата.
Следовательно, один квадратный файл подходит и для превью, и как эталон сцен 2:1
и листов эмоций 4:3. Дополнительные горизонтальные эталоны не нужны.
На этом этапе проверены файлы и существующий код; реальные задания диалогов не запускались.

## Метаданные

assets.json — метаданные подготовки ресурсов, приложение их не читает.
В нём записаны шаблон папки с {mode}, стабильный id, подпись, имя WebP
и предлагаемая текстовая инструкция для каждого стиля.
Рабочий каталог этапа 2 находится в server/src/features/aiDialogue/illustrationStyles/catalog.ts:
id, ключ клиентского перевода titleKey, file и stylePrompt. Переводы названий
находятся в face/messages/{locale}.json. Рабочий ключ строится функцией
getAiDialogueIllustrationStyleKey из MainConfigService.get().mode и file.
Превью и эталон используют один файл; подробный контракт — в документации этапа 2.
Эти инструкции ещё не проверены на реальных заданиях NPC и сцен.

generation-prompts.md содержит точные промпты трёх выполненных вызовов image_gen.
Промпты создания демонстрационных картинок и инструкции будущего генератора —
разные данные: в будущие задания нельзя переносить описание конкретного отеля
или этих двух женщин.

## Добавление и замена файлов в будущем

Новый стиль: новый стабильный id, запись каталога и WebP в нужных папках MODE.
Замена эталона существующего стиля: перезаписать файл с тем же именем в папке MODE.
Версии и архив прежних эталонов не предусмотрены.
Задания сохраняют ключ, а не копию байтов референса: ещё не обработанное задание
после замены прочитает новый файл. Готовые изображения диалогов не меняются.
При подключении UI учитывать обновление подписанных ссылок/кэша после замены файла.
